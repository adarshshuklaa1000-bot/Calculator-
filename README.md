# Adarsh Calculator Pro

**Powered by Adarsh Shukla**

A static, responsive all-in-one calculator suite.

### Included
- Dashboard / home
- Basic calculator + keyboard + memory
- Scientific calculator
- Finance: Simple Interest, Compound Interest, EMI, GST, Discount, Profit/Loss, SIP, Percentage
- Math: HCF/LCM, Average, Quadratic Equation, Prime Checker, Fraction Calculator
- Converters: Length, Weight, Area, Speed, Volume, Time, Data, Pressure, Temperature
- Age calculator and date difference
- Local history
- Dark/light mode
- Precision setting
- Mobile responsive UI
- No backend/API required

### Vercel
Upload these files to GitHub, import the repo in Vercel, choose **Other** as framework if asked, leave build/output settings empty, and deploy.

### GitHub Pages
The project is static and can also be deployed through GitHub Pages.
