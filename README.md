# Free Study Calculator Pro

Advanced browser-first calculator suite by Adarsh Shukla.

## Included
- Cinematic Free Study splash screen with animated logo, inner/outer rings, particles, orbit effects, animated brand text and 0–100% loading.
- Basic calculator with keyboard input, memory, copy, undo and local history.
- Smart phrase calculator.
- Scientific calculator with trig, logs, powers, constants and factorial.
- Finance tools: SI, CI, EMI, GST, discount, profit/loss, SIP, percentage, tax, inflation and break-even.
- Unit converters including temperature, length, weight, area, speed, volume, time, data, pressure, energy, power, frequency, force, torque, fuel, angle and cooking.
- Math tools: HCF/LCM, average, quadratic, prime, fractions, ratios, permutations/combinations and 2×2 matrices.
- Statistics analysis.
- Date/time tools: age, date difference, countdown and stopwatch.
- Student/utility tools: BMI reference calculator, unit price, proportion, percentage change and programmer base conversion.
- Searchable local history with TXT/CSV export.
- Favorites.
- Dark/light/system theme, accent colors, precision control and optional click sound.
- Fullscreen mode and installable PWA support.
- Offline caching through service worker after the first successful load on HTTPS/localhost.

## Run
Open `index.html` in a browser. For PWA/offline installation, deploy over HTTPS (or use localhost).
